# WALLPANEL
 WallPanel is a customizable Android wallpaper and widget application that transforms your home screen into a personalized information dashboard.  Users can choose their own wallpaper and place customizable widgets such as clock, date, weather, battery, network status, device information, calendar, custom text, and images directly over the wallpaper.  ✨ Key Features  - 🎨 Custom wallpaper selection - 🕐 Digital & analog clock widgets - 📅 Date and calendar widgets - 🌤️ Live weather information - 🔋 Battery status - 📶 Network/Wi-Fi information - 📱 Device information - 📝 Custom text widgets - 🖼️ Image widgets - ↔️ Drag, resize and rotate widgets - 🎨 Custom fonts, colors, opacity and styles - 💾 Save and reuse custom wallpaper designs - 🌙 Modern dark-themed interface - ⚡ Optimized for smooth performance and low battery usage  🛠️ Technology  Built with Kotlin, Jetpack Compose and Android Live Wallpaper APIs, with local storage for saving customization settings.  WallPanel is designed to give Android users a flexible way to create their own personalized live wallpaper dashboard without requiring root access.
